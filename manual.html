第一部分｜心法、心态与理念

1. 幸福教练是谁

幸福教练是实战班交付体系的最小执行单元，也是学员每天最容易接触到的一线交付者。

  • 一线交付者：一名教练背后，是一组家庭、一段段关系和一份份信任。
  • 第一触达人：主教练负责统筹，副教练负责托举，但学员每天看到的，往往是幸福教练的链接、点评、提醒和陪伴。
  • 人才培养单元：幸福教练不是临时帮忙，而是副教练、主教练和总统筹的人才池。
  • 成长路径：幸福教练 → 副教练 → 主教练 → 总统筹。

2. 三不三要

不要把自己当成要成为工作含义
执行者内观者先归因于己，借事修己；外部反馈是发现自己沟通盲区的线索。
拯救者扶正者用发问代替给答案，用看见代替说教，让学员自己长出能力。
临时工准教练在承担中训练，在实战中成长，自己成为榜样，才有资格成为标准。

3. 三心、五种底层思维

三心

爱心、耐心、细心。

五种底层思维

  1. 归因思维：遇到问题先看自己能调整什么，不把责任全部推给家人或学员。
  2. 内观思维：情绪升起时先看见、接住、消化，不被情绪牵着走。
  3. 扶正思维：像给小树插竹竿，提供方向和支撑，但不替对方生长。
  4. 利他思维：服务不是替人完成，而是激发对方自己解决问题的能力。
  5. 榜样思维：先看见一个人的光点，再把可复制的规律讲清楚，让一个人的改变带动一群人。

4. 幸福驾校四科目模型

科目学员变化教练核心任务关键结果
科目一：学幸福交规不知道 → 知道规则链接、建档、讲清学习路径、激活参与学员接上车，知道去哪学、怎么学、找谁问
科目二：练幸福实操知道 → 做出动作看见突破、发问引导、推动回家践行和反馈学员把课程用进真实家庭场景
科目三：跑幸福路考动作 → 生命被影响找榜样、录素材、双重点评、进入高能量圈子学员被持续看见，改变被放大和传播
科目四：拿父母驾照实践 → 通过验收场景复盘、成果表彰、结营发证、持续陪伴学员看见自己的改变，并愿意继续践行

四个科目不是割裂的四段，而是同一条成长链：认知打开，行为才动得起来；行为持续，生命才真正发生改变；生命改变，结营验收才有结果。

5. 服务边界

应该做

  • 先建立温暖链接，再进入任务和问题。
  • 先看见优点，再指出可以提升的地方。
  • 用问题、故事、例子和规律，引导学员自己得出结论。
  • 把学员送到合适的会议室、教练和岗位资源上。
  • 对失联、未进群、未作业、持续卡点及时上报，不让问题过夜。

不应该做

  • 直接给“标准答案”，替学员做决定。
  • 只盯缺点、只催作业、只做机械通知。
  • 把行动会议室和榜样会议室说成“有问题的人才去”。
  • 在没有准备时自由发挥、喧宾夺主或过度承诺。
  • 把自己的情绪、判断或焦虑转嫁给学员。

从学习者到幸福教练：先走过，再陪伴

幸福教练大多是从学习人中成长出来的。成为教练，不代表自己已经“什么都会”，而是愿意把自己走过的路、踩过的坑和正在练习的动作，拿出来陪另一位家人一起走。

可以把成长分成四步：

  1. 先把自己的学习做好，能听懂、能练习、能反馈。
  2. 开始学会看见别人，不只看问题，也看见努力和变化。
  3. 学会用问题、故事和具体表达陪伴别人，而不是急着替别人解决。
  4. 能独立承担一个岗位，也愿意把经验分享给新伙伴。

遇到接不住的情况，不需要一个人硬扛。可以把场景、已经做过的动作和仍然卡住的地方带给副教练、主教练或答疑老师一起看。求助不是能力不够，而是对学员负责。

语言温度：标准清楚，表达柔和

手册中的标准要执行，但可以用更容易被接受的方式表达：

原有表达建议在陪伴中这样说
必须完成这一步建议优先完成，它会让后面的服务更顺。
你怎么还没有行动你现在是卡在不知道怎么做，还是还没有找到合适的时机？
不能让学员掉队我们尽量让每一位学员都有人关注、有人回应。
你要改变自己我们先看看自己这边有没有一个可以调整的小动作。
你应该想清楚我们一起把场景拆开，也许方向会慢慢清楚。
不合格，重新训练这一步还不熟，我们再一起练一遍，练到你有把握为止。

保留“内观、扶正、赋能、榜样”等项目语言，但第一次出现时要翻译成白话：内观就是先看看自己能调整什么；扶正就是先看见对方做对的地方；赋能就是让对方以后自己会做；榜样就是把真实有效的好动作讲清楚。

第二部分｜流程与标准

6. 全周期总流程

交付前期：前置铺垫，筑牢陪伴根基

核心：工作前置，提前准备。

  1. 吃透课表：知道每节课的时间、主题、主讲人、会议形式，以及对应解决哪类家庭难题。
  2. 核对名单：逐一确认学员是否进群、是否按规范修改昵称。
  3. 建立档案：收集家庭关系、当前痛点、学习经历、参会状态和后续变化。
  4. 建立链接：让学员知道“有人跟进、有人答疑、有人托底”。
  5. 熟悉工具：会引导签到、查看课程、写作业、提交后台、查回放、看群公告和课程表。
  6. 明确分工：知道自己、幸福教练、副教练、主教练及各会议室的责任边界。

交付中期：紧盯落地，及时托举成长

核心：盯全程、推践行、解卡点、抓反馈、放大改变。

  • 听课不是结果，回家实操才是结果。
  • 实操后要有反馈，反馈才能帮助教练判断下一步怎么引导。
  • 学员有卡点：进答疑会议室；想对标榜样：进榜样会议室；当天有收获或困惑：参加小组复盘。
  • 看到学员的细微改变，要及时具体肯定，把“我做不好”托举成“我有能力改变”。

交付后期：沉淀成果，挖掘榜样，连接长期学习

核心：找榜样、做结营、促长期。

  • 回看学员整个周期的听课、作业、落地和反馈。
  • 按“思维、行为、结果、带动”识别小榜样、中榜样、大榜样和更大榜样。
  • 收集真实素材，准备点评稿、奖状和结营环节。
  • 说明结营不是终点，持续听课、落地、反馈和复盘才是长期路径。

14天项目的开营前组织顺序

按新版流程材料，组织顺序为：先搭建团队并完成定岗 → 再搭建后台与班级社群 → 完善群规、管理员和权限 → 先邀请助教、总教练和董助/教练团队 → 最后统一邀请学员进群。原则是先把管理团队和社群秩序准备好，再接入学员。

9. 幸福教练日常标准动作

每天三件事

  1. 早课后：提醒学员，有卡点就进答疑值班会议室。
  2. 下午：提醒学员，有收获、有突破就进榜样筛选/榜样会议室；行动有阻力就进工行动会议室。
  3. 晚复盘：复盘当日所学所做，及时反馈学员状态、问题和可复制案例。

六大互动阵地

会议室后台、微信群、作业下方、早课复盘会议室、私信留言、面对面通话。

核心动作不是“到处刷存在感”，而是在合适的阵地完成三步：看见表现 → 留下具体点评/问题 → 给出下一步入口。

14天每日备课十步

  1. 回顾昨晚课程，提出问题并给出方案。
  2. 熟读当日课程完整流程、课程精要和核心知识点。
  3. 聆听“一分钟音频”，全员集中讨论。
  4. 从助教/成人视角拆解课程核心、收获和难点。
  5. 从孩子视角拆解：孩子能听懂什么、会困惑什么、需要怎样引导。
  6. 用AI辅助生成岗位通用稿件初稿。
  7. 拆分主持稿、话题官稿、游戏官稿、签到官稿等岗位稿件。
  8. 由副教练审核、修改和定稿。
  9. 精准下发给当天承担岗位的学员。
  10. 课后与岗位学员一对一复盘，并提前制作问题图片、短视频等物料。

14天每日四段式授课

  1. 教练开场：公布团队和个人积分，调动氛围。
  2. 行动复盘：回顾昨日课程，检查昨日落地行动。
  3. 学员主导：完成交接，由当班学员呈现当日课程环节。
  4. 教练收尾：点评积极学员与亮点，总结核心知识点，布置课后作业并完成闭环。

开营、结营均采用“策划 → 撰稿 → 选人 → 彩排 → 落地呈现 → 复盘”的闭环。

10. 四科目执行要点

科目一：学幸福交规

  • 逐一链接学员，确认进群、昵称、资料和课程表。
  • 讲清四科目学习路径、每日课程、作业提交和求助路径。
  • 通过学员原始资料发问：带着什么问题来？希望在哪方面改变？愿意承担什么岗位？
  • 激活学员承担点评、统计、值班、分享等角色。
  • 学员未参会且联系不上时，及时向副教练上报。

科目二：练幸福实操

  • 关注学员的三个变化：思维上知错、行为上改变、结果上让身边人感受到正向变化。
  • 推动“听课—回家实践—群内反馈—再次调整”的闭环。
  • 让学员知道行动会议室和榜样会议室都是资源，不是门槛。
  • 每两天上报一次未参会、未作业或持续无反馈的学员名单，具体以当届通知为准。

科目三：跑幸福路考

  • 从榜样会议室、小组复盘、群语音/文字、后台作业中找素材。
  • 晚复盘学员分享时，为自己负责的学员录视频，连同作业发给榜样官或班委群并@相关负责人。
  • 通过主讲点评＋后台互动点评制造“被看见”的双重能量。
  • 结营前提前准备奖状、点评稿和学员成长故事。

科目四：拿父母驾照

  • 用真实家庭场景做验收，不考“背会了多少”，考“做到了什么、生命变了什么”。
  • 结营仪式上让学员被公开看见、被具体肯定。
  • 按本届规则提醒电子档案、父母驾照、问卷、作业和回放等收尾事项。

11. 关键岗位协同

交付团队四级角色总览

《幸福驾校》的交付，不是靠某一个人把所有事情做完，而是四个角色各自站好位置、彼此托举：

角色角色定位主要交付结果
总统筹交付体系的设计者、发动者和持续升级者人选合适、团队被激活、流程可复制、学员有获得感
主教练一期交付的全局负责人方向清楚、分工清楚、关键节点稳、问题能闭环
副教练幸福教练队伍的托举者和陪练者教练有人带、有人练、有人反馈，逐步能够独立承担
幸福教练连接学员的一线陪伴者学员有人联系、有人看见、有人引导，变化能被记录和反馈

工作链路可以记成：

总统筹定方向、建体系、出创意 → 主教练把方向变成交付计划 → 副教练把计划变成团队动作 → 幸福教练把动作带到学员身边 → 学员反馈再回到团队和体系。

部分原文使用“总教练”这一称呼，本手册统一使用“主教练”。如果某一届同时设置“总教练”和“主教练”，以当届组织架构为准，提前写清两者的分工，避免重复指挥。

总统筹：三个核心能力

1. 识人、用人、带人、激活人

总统筹首先要看见人，再安排事。识人，不只看谁能力强，也看谁愿意承担、时间是否匹配、是否有责任心、是否认同家庭教育和利他服务；用人，是把合适的人放到合适的位置；带人，是给清楚目标、标准、资源和反馈；激活人，是让伙伴知道自己为什么做、做成后能帮助谁，也能在承担中看见自己的成长。

可以用四个问题做安排前的快速判断：

  1. 这个人愿不愿意承担？
  2. 他的时间和精力是否匹配？
  3. 他目前最适合从哪个岗位开始？
  4. 我能给他什么支持，让他愿意开始并做得下去？

总统筹要做的，不是把所有岗位都抓在自己手里，而是让更多合适的人有机会承担、被看见、被培养，逐步形成“老带新、边做边学、有人接续”的队伍。

2. 完善交付流程与标准

流程和标准的价值，是让新人有路可走，让伙伴知道做到什么程度，让学员在不同岗位上都能得到稳定的陪伴。

总统筹需要持续做四件事：

  • 把成功经验沉淀成流程、清单、模板和案例。
  • 把岗位边界、交接节点、时间要求和验收方式写清楚。
  • 在真实交付中观察哪里卡、哪里重复、哪里容易漏，再调整标准。
  • 让流程既能保证质量，也给伙伴留下温度、判断和创造的空间。

好的标准不是让大家变得机械，而是让大家少走弯路，把更多精力放在学员身上。

3. 让学员获得感的创新与创意

创新不是为了热闹，而是让学员在学习过程中感到：我被看见了、我有参与、我真的有变化、这段经历值得继续。

总统筹可以持续关注四个问题：

  • 学员在哪个时刻最容易迷茫或掉队？
  • 哪些小细节能让学员感到有人陪着？
  • 学员的改变怎样被记录、被表达、被公开肯定？
  • 课程、会议室、群运营和结营环节，怎样让学习更有参与感和记忆点？

创新可以是一句及时的点评、一份有针对性的资料、一次让学员参与的主持、一个把改变留下来的视频，也可以是结营时对成长故事的真诚呈现。关键不在形式多大，而在是否真正回应了学员的需要。

四个角色之间如何交接

交接方向需要交清楚的内容
总统筹 → 主教练本届目标、团队配置、交付标准、创新重点、关键风险
主教练 → 副教练岗位分工、时间节点、验收要求、资源入口、升级路径
副教练 → 幸福教练负责学员、每日动作、会议室安排、可用模板、遇到问题找谁
幸福教练 → 副教练/主教练学员参会、作业、卡点、改变、榜样素材和未闭环问题

每次交接都尽量回答五件事：谁负责、做什么、什么时候做、做到什么程度、遇到问题找谁。

幸福教练

链接学员、建档、讲清规则、提醒参会、跟进作业、识别卡点、引导会议室、发现榜样、收集反馈、上报异常。

原文归纳的七项基本工作，作为新人上岗时的完整检查口径：

  1. 确认自己班组的组织架构和学员名单。
  2. 核实本组学员身份；未进群或未修改昵称，及时上报副教练。
  3. 指导学员填写平台“学员信息”或完成自我介绍，收集成长基础信息。
  4. 熟悉本期线上课表，能向学员说清课程时间、主讲老师、内容和会议形式。
  5. 熟悉平台音频课程，能引导学员写作业、提交并转发到学习群。
  6. 了解平台社群规则和群公告位置，提醒学员按时参加会议。
  7. 结营前提醒学员完成作业保存、学分/小鱼、回放、调查问卷和电子档案等收尾事项，具体期限以本届通知为准。

全程有四次重要大会：全员开营仪式、两次学员大复盘、全员结营仪式。

副教练

核心不是代劳，而是激活、托举、考核：先点评优点，再谈任务；把主持、通关、结营、奖状等成长机会分给幸福教练；关键时刻兜底；从做事态度中识别骨干。

主持/副主持/课程主持/控麦/互动/截屏

  • 会前：熟悉流程、准备逐字稿、对接主讲或采访官、调试设备、提前开启云录制。
  • 会中：课程主持负责开场、串场、交麦、时间把控和结束语；控麦主持负责麦克风和视频；副主持负责功能设置、录制补位和突发状况；互动主持负责后台互动与金句整理；截屏主持负责名单和精彩互动留档。
  • 会后：立即复盘，内容包括做得好的点、可提升点、受到的启发；复盘控制在30分钟内，并完成岗位交接。

答疑值班

值班时记录学员问题、现场解法、参会名单和排麦名单；会后将“排麦截图＋会议记录”发班委群，形成“看见问题—记录问题—跟进问题”的闭环。

榜样官与榜样库

榜样官对接本组幸福教练，每天收集突破素材，推送至榜样素材群；素材需标注组别、姓名、新报/复训、赛道、突破点和简单总结。统计负责人按赛道和突破点归类入档。

榜样等级按原文可这样理解：小榜样是认知开始松动、愿意自省和尝试；中榜样是认知与行为都开始改变；大榜样是出现了家庭或关系中的正向结果；更大榜样是在自己改变后，还能主动带动身边人一起成长。评选时看完整轨迹，不只看一次发言。

12. 通关与验收

采用循环通关：A通B，B通C，C通D，D通A；由上一级验收。通关流程中出现不合格单点，重复训练直至合格；合格后由验收人明确宣布“流程标准，顺利通关”。

通关验收关注三件事：是否理解、是否能复述、是否能在真实场景中执行。

第三部分｜服务技巧

13. 点评：人＋一个优点＋具体场景

合格公式

“我想点评的是____，你特别____，因为今天____这件事，我看见了。”

三要素缺一不可：

  • 人：明确点评谁。
  • 优点：只抓一个品质，不堆砌形容词。
  • 具体场景：落到一件真实发生的小事。

每日三条练习

  1. 给伴侣/家人：看见他今天为家庭做的一件付出。
  2. 给孩子：锁定一个细节，肯定其中的善意或体贴。
  3. 给自己：看见自己的不容易，先不评判，给自己一句肯定。

空夸：“你真好、你真棒、你很懂事。” 具体点评：“我想点评的是馨悦，你很细心，因为今天你默默给弟弟夹了一筷子菜这件事，我看见了。”

14. 发问代替说教

五步发问框架

  1. 还原场景：刚刚发生了什么？你怎么说、怎么做的？
  2. 看见目标：你希望关系变好，还是只想让对方马上听话？
  3. 回到自己：这个结果里，我能调整的动作是什么？
  4. 对照规律：如果继续这样做，关系会变好还是变差？
  5. 设计下一步：今天准备先做哪一个小动作？什么时候反馈？

示例句

  • “你现在是在解决问题，还是在急着马上搞定对方？”
  • “你能改变家人吗？如果不能，今天你能先改变哪一个动作？”
  • “如果孩子这样对你，你希望他未来成为怎样的人？那你今天要先种下哪一颗种子？”
  • “你听到的规律，准备怎样用在今天这一个具体场景里？”

15. 抱怨、指责和外归因的处理

处理顺序：接住情绪 → 不跟着抱怨 → 把注意力带回自己 → 让学员做一个可执行的选择。

典型引导

  1. 面对抱怨孩子：问“现在是在教育孩子，还是在教训孩子？”引导学员区分直接给答案与讲故事、举例、发问。
  2. 面对抱怨家人：问“我们学习是扶正还是祛邪？现在看到的是优点还是缺点？”
  3. 面对外归因：用“方向—方法”的比喻，先确认幸福的方向是内观自己，再讨论下一步方法。
  4. 面对急于要话术：先确认学员是否在追求“马上搞定”，再把问题带回关系、发心和自己的动作。

16. “止血—消毒—包扎—休养”案例动作

这是答疑案例中的冲突处理比喻，适用于帮助学员先停止伤害性表达，再恢复关系，不是医疗建议。

  1. 止血：先止住恶语、负面情绪和继续争辩。
  2. 消毒：停止重复伤害，转念看见自己的责任。
  3. 包扎：把“我错在哪里、过去哪里没有做好”具体表达出来。
  4. 休养：用关心、倾听、具体陪伴和持续正确动作，让关系逐渐修复。

17. 会议室引导技巧

答疑会议室

适用：卡点不清晰、无法找到突破方向、情绪反复、需要现场拆解。

引导语：

“你这个问题不需要一个临时话术，更需要把方向照清楚。今天可以先进答疑会议室，把发生的场景、你说的话和你想要的结果讲出来，老师会带你一起拆。”

榜样会议室

适用：有收获、出现突破、想看别人怎么做、需要被榜样带动。

引导语：

“榜样会议室不是只有榜样才能进，而是用来学习别人做对的规律。你可以进去听一个真实案例，再看看哪一个动作能复制到自己的家庭。”

小组复盘

适用：当天学习后的消化、反馈、复盘和问题前置。

引导语：

“今天先不用追求讲得完美，把你听到的一条规律、做过的一个动作、遇到的一个卡点带到复盘里，团队一起把它梳理清楚。”

18. 识别和托举学员改变

观察四类证据：

  • 认知：从“都是别人的问题”变为“我也能看见自己的因”。
  • 行为：从抱怨、命令、说教，变为表达、发问、倾听和具体行动。
  • 关系：家人愿意靠近、愿意表达、冲突减少或出现正向回应。
  • 带动：主动分享、点评他人、承担岗位、帮助别人进入正向循环。

反馈句式：

“我看到你这次不是只听懂了，而是已经做了____。尤其是____这个细节，说明你开始把规律用进生活了。下一步可以继续保持____，再把结果带回群里。”

19. 答疑案例库：按场景陪伴，不照搬答案

下面的案例来自《答疑会议室案例分析整理》。案例不是固定话术，也不是要求幸福教练逐字复制；使用时先听清场景，再从“发生了什么—学员想要什么—自己能调整什么—下一步做什么”进入。每个案例都保留了原文中的方向、比喻和关键提问，方便在相似场景下查阅。

案例一：孩子睡懒觉、不自律，家长不知道怎样引导

场景：孩子长期睡懒觉、不上班或没有规律，家长知道不能用负面话伤害孩子，但一开口还是容易批评，也不知道怎样说才有效。

原文方向：先把问题从“孩子怎么这样”带回“我过去有没有给孩子培养好习惯”；从看缺点转向看优点，从给答案转向发问。

陪伴路径：

  1. 先问：“孩子现在这个结果，我们能不能也看看自己这边的原因？”
  2. 再问：“我过去在哪些地方没有给孩子更好的引导？”
  3. 如果发现自己以前做得不够，可以具体表达：“妈妈以前没有帮你培养好这些习惯，这部分妈妈有责任，不全是你的问题。我们接下来一起慢慢练，好吗？”
  4. 用发问引导孩子想象：“如果你交朋友，你喜欢一个爱讲卫生、比较自律的同学，还是不自律的同学？那我们以后想成为怎样的人？”
  5. 约定一个小动作，第二天带着结果回到群里反馈。

原文案例中的四步比喻：止血——先止住恶语和负面情绪；消毒——停止继续伤害并转念；包扎——把自己错在哪里表达出来；休养——用关心、倾听和持续的正确动作，让关系慢慢修复。

案例二：伴侣有情绪，自己一着急就想顶回去

场景：伴侣容易带着情绪说话，家长也会被激怒，虽然知道要温柔，却不知道怎样止住自己的情绪。

原文方向：不能改变伴侣时，先把注意力放回自己；“盆子和大海”“天和地”的比喻，都是帮助学习人扩大承载力。

陪伴路径：

  1. 先问：“你现在能改变伴侣吗？如果不能，今天能先改变自己哪一个动作？”
  2. 用“墨水倒进盆里和倒进大海”的比喻，帮助对方看见：同一件事放在不同的承载里，结果不同。
  3. 用“天和地”的比喻追问：“地本来不平静时，如果天再下冰雹、刮大风，会不会让家里的树更受伤？”
  4. 先做“止语”：暂停争辩，等情绪缓下来，再进入表达和沟通。
  5. 下一步只练一个动作，例如今天先不顶回去，观察自己的语气和眼神，晚上复盘结果。

案例三：孩子沉迷手机、晚睡，家长总想马上把问题解决

场景：孩子玩手机、打游戏、晚睡，家长每天盯着时间和结果，越提醒关系越紧张。

原文方向：“教育孩子是种种子的过程，不是拔草。”先整理自己的土壤，再谈怎样给孩子种下时间管理、身体健康和自律的种子。

陪伴路径：

  1. 先问：“我现在是在盯着一棵草，还是准备给孩子种下一颗种子？”
  2. 先承认自己的责任：“妈妈以前没有帮助你培养时间管理和作息，这部分是妈妈没有做好。”
  3. 不直接否定孩子喜欢的游戏，可以先了解他在玩什么、为什么喜欢，再一起讨论“该玩时玩、该休息时休息”的安排。
  4. 用孩子熟悉的自然规律做引导，例如日出而作、日落而息，让孩子自己说出身体和作息的关系。
  5. 观察孩子的表情和回应：愿意靠近、愿意说话，是关系变好的信号；如果明显抗拒，先减少表达量，重新调整方式。

案例四：成年孩子不愿结婚，家长担心孩子恐惧婚姻

场景：成年子女不想结婚，家长发现自己夫妻关系时好时坏，孩子可能因此对婚姻缺少信心。

原文方向：先承认“不是婚姻不能幸福，而是我们过去不会经营”；把父母关系中的变化和责任，用孩子能接受的方式表达出来。

陪伴路径：

  1. 先看自己：“我过去是否经常只看伴侣缺点，沟通方式是否给孩子带来不安全感？”
  2. 可以对孩子表达：“妈妈以前不会经营家庭，常常只看到爸爸的缺点，也没有把幸福经营好。妈妈现在开始学习，才知道家庭是需要经营的。”
  3. 不催孩子立即结婚，而是让孩子看到：关系是可以学习和经营的。
  4. 继续改变自己的表达和夫妻相处，让孩子先看到真实的变化，再慢慢恢复对关系的信心。
  5. 原文强调：这里要给方向，不是递一套“马上见效的方法”。

案例五：异地陪伴只剩发信息，孩子觉得“不懂我”

场景：家长与丈夫或孩子不住在一起，每天会发信息，但内容多是提醒、批评、转发吸烟喝酒或打游戏的视频，关系越来越远。

原文方向：钱和提醒不等于精神陪伴；“狗喜欢骨头、小白兔喜欢胡萝卜”的比喻，强调“懂比爱更重要”。

陪伴路径：

  1. 先问：“我发的内容，是对方真正需要的，还是我自己认为有用的？”
  2. 不把钱、物质和提醒当成全部的爱，可以表达：“妈妈以前以为给你更好的条件就是最大的爱，现在才发现，还需要心与心的陪伴。”
  3. 先了解孩子喜欢的游戏、朋友和生活，不马上评价对错。
  4. 对打游戏、喝酒等行为，不用视频去“让对方照镜子”，先理解行为背后的放松、孤独或压力，再回到时间管理和身体健康。
  5. 信息发送前，可以先让幸福教练帮忙看一遍：这句话会让对方更愿意靠近，还是更想躲开？

案例六：想道歉、想表扬，孩子却说“闭嘴”或明显抗拒

场景：家长已经开始学习，也会笑着表达，但孩子仍然不愿意听，甚至刚开口就打断、转身或说“你还有几句话”。

原文方向：内观不能只停留在“我反省了”，还要问清楚错在表达内容、眼神、语气、时机还是表达过长。

陪伴路径：

  1. 可以直接而温和地问：“刚才是妈妈的表达、眼神还是语气让你不舒服？你愿意告诉妈妈吗？”
  2. 先听孩子的反馈，不急着解释“我明明是为你好”。
  3. 检查内容是否真的是孩子需要的。原文用“小白兔不吃骨头，只喜欢胡萝卜”说明：即使没有情绪，给错了内容，对方仍然不会接受。
  4. 避免长篇大论，只说一个优点、一件事、一句表达。
  5. 用孩子的表情和回应判断是否做对：愿意靠近、愿意回应、表情放松，说明方向可能更合适；明显躲避时，先停下来。

案例七：孩子答应了却没有做到，家长只盯着结果和事情

场景：孩子答应早起、上课或回家参加活动，但后来没有做到；家长继续追问事情本身，忽略了孩子当时的情绪和状态。

原文方向：先关注人，再关注事；先看孩子的表情、情绪和状态，等关系和状态稳定后再谈事情。

陪伴路径：

  1. 不先问“你到底去不去”，而是问：“你这几天是不是有什么不舒服或不开心？妈妈是不是有哪个动作让你不舒服？”
  2. 先关注人：今天心情怎样、身体是否不舒服、发生了什么。
  3. 等孩子状态好一些，再谈上课、回家或活动安排。
  4. 用“做菜先洗菜”的比喻提醒自己：顺序错了，后面的动作越努力，结果也未必理想。
  5. “为什么”是找原因，“是什么”是看结果；先找到原因，再决定下一步。

案例八：学了很多，还是不会表达，也没有真正实战

场景：学习人听过很多课程，知道很多道理，但一到和家人沟通就不会说，也不敢开口，觉得自己“学了不会用”。

原文方向：把学习比作做菜：只听别人讲满汉全席，不等于自己会做；需要买材料、照步骤做、尝结果、再调整。

陪伴路径：

  1. 先选一道“小菜”，不要一次解决所有家庭问题，只选今天最想表达的一句话。
  2. 先写或说出来，不要求一次完美。
  3. 把表达发给幸福教练，请教练帮忙看：是否有具体对象、具体场景、合适语气和清晰重点。
  4. 做完带回结果：家人怎么回应、自己的情绪怎样、哪个动作有效。
  5. 根据反馈调整“盐和醋”，连续练几天，直到形成自己的表达方式。

案例九：孩子在工作中遇到强势同事，家长想替孩子出气

场景：孩子与强势同事发生不愉快，对方的说法虽然有一定道理，但态度强硬；家长也跟着生气，担心孩子受委屈。

原文方向：先看见孩子没有对抗、能够包容的一面；承认别人暂时无法改变，再把注意力放回自己的选择。

陪伴路径：

  1. 先点评孩子做对的地方：“你虽然不舒服，但没有马上和对方发生冲突，这说明你有分寸、有承载力。”
  2. 再问：“你喜欢强势对待别人的人吗？如果我们也用同样的方式，别人会喜欢吗？”
  3. 继续问：“这个同事你能改变吗？如果不能，你想先把自己做成一个怎样的人？”
  4. 用“碗和盆子”的比喻帮助孩子理解：几只同样大小的碗容易互相碰撞，盆子代表更大的承载和包容。
  5. 最后把这次经历沉淀成一颗种子：遇到强势的人，先守住自己的表达和边界，不急着用同样的方式回击。

案例十：孩子以3000元为条件才愿意上学

场景：孩子不愿上学，提出给钱才去；家长一边担心孩子，一边不断劝说，也不知道怎么处理才不会形成新的条件交换。

原文方向：先看清“给钱”是一个临时方法，还是在培养孩子解决问题的能力；把“解决眼前上学”拉回到人际关系、抗压能力、价值观和长期成长。

陪伴路径：

  1. 先问：“给3000元能解决孩子哪一种长期能力？如果下一次要5000元、1万元，怎么办？”
  2. 看孩子的家庭土壤：父母关系、语言、眼神、语气，是在往鱼池里扔垃圾，还是在清理鱼池？
  3. 不急于推课程或介绍方案。原文提醒：先把原理讲清楚，让对方自己选择；“给鱼”只能解决一次，“教会钓鱼”才是获得长期能力。
  4. 把问题从“孩子现在去不去学校”扩展为：“未来到了单位、进入社会，遇到挫折和人际问题时，孩子有没有能力面对？”
  5. 引导家长看见：教育是种种子，不是拔草；今天要种下的是人际能力、抗压能力、责任感和正确价值观。
  6. 幸福教练要把握边界：提供方向、陪伴选择和安排合适的答疑资源，不长时间替对方处理全部问题，也不承诺一次解决。

20. 答疑常见问题的短模板

面对抱怨孩子

可以先问：“我们现在是在教育孩子，还是在教训孩子？”

如果对方说“教育”，继续问：“你觉得教育和教训有什么不同？直接把答案告诉孩子，还是通过故事、举例和发问，让孩子自己想明白？”

最后收束：“那我们下一次可以先少说一个答案，多问一个问题，让孩子自己说出想法。”

面对持续抱怨家人

可以先问：“我们学习以后，是为了扶正，还是为了祛邪？”

再问：“现在我们看到的是家人的缺点，还是也能看到他做对的地方？”

最后落地：“今天先找一个真实发生的小事，把那个优点具体说出来。”

面对总是指责别人

可以用“导航去目的地”的比喻：方向确定后，交通工具可以不同，但都能到达；家庭想幸福，方向先回到自己，方法再根据具体场景调整。

可继续问：“今天这件事里，我能调整的表达、语气、眼神或动作是什么？如果我把错误动作停下来，把正确动作持续做，关系会不会出现新的变化？”

30. 主持人会前/会中/会后

会前

  • □已知晓会议内容并完成主持逐字稿。
  • □已与主讲老师/榜样采访官确认交接麦节点。
  • □手机亮度调高、自动锁定设为“永不”、铃声静音。
  • □不使用蓝牙耳机，提前15分钟进会调试。
  • □已开启云录制并安排副主持补位。

会中

  • □课程主持、控麦、互动、截屏职责已确认。
  • □开场签到、昵称规范和团队提醒清晰简洁。
  • □交麦准确，不自由发挥，不喧宾夺主。
  • □对分享者留悬念，不提前说完全部信息。
  • □关注时间，文字提醒后必要时语音提醒。
  • □随时记录金句和亮点，准备自然结束语。

会后

  • □听到“再见”后停顿3秒，再结束云录制和会议。
  • □立即组织复盘，最多30分钟。
  • □完成当场问题、解决方案和下一场交接。

主持串词骨架

这是一份“结构模板”，不是要求每个人说成同一个声音：

  1. 开场：问候学员，欢迎大家进入会议室；通过城市、天气、心情或营养用餐做轻量签到。
  2. 提醒：请大家按统一格式修改昵称，提醒各组教练关注未进会的学员。
  3. 破冰：讲一个自己的学习收获，或用与当天主题有关的小故事介绍主讲老师，控制在约5分钟内。
  4. 交麦：简洁说明“接下来由谁分享、分享什么”，把麦准确交给主讲或嘉宾。
  5. 介绍榜样：介绍已知信息，但给分享者留一点悬念，不替对方全部说完。
  6. 控时：提前用文字提醒，临近结束再用语音提醒；根据现场情况灵活调整。
  7. 结束：预告下一步课程、作业和群内分享；以“再见”作为结束信号，听到信号后停顿3秒，再结束录制和会议。

一页速记：幸福教练的工作总纲

先连接，再引导；先看见，再点评；先发问，再给方向；先推动落地，再收集反馈；先托举改变，再沉淀榜样。

“科目一把人接上车，科目二把动作练出来，科目三把生命跑开，科目四把成果验收发证。”

最终只做一件事：用陪伴，把学员从知道带到做到，再带到绽放。
